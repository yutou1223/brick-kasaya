## 页面结构

文档是一段带对话的场景描写，按叙事节奏重新编排：

1. **标题区**：`誓向西行` / `长安月 · 大雁塔下的一句话`
2. **场景开头**：长安城外、大雁塔下，风从西边吹来
3. **核心誓言**：`佛不东去，我便西去。` 用引文块单独立起
4. **三段师徒对话**：每段左侧金色细线 + 说话人小字（旁边的小沙弥／他说／小沙弥急了）
5. **经书与一碗水**：和尚取残破经书的独白，保留原文引号叙述
6. **夜行收束**：出城、塔灯变小、月亮在前，最后两句用细虚线分隔并加重，落在"有些路，总要有人先走"
7. **文化小剧场**：文档中的三段史料（那句誓言的含义／大雁塔与四年五万里／真实的玄奘与《西游记》）

## 双语跳转规则

入口页读取 `navigator.languages`：任一项以 `zh` 开头（`zh`、`zh-CN`、`zh-TW`、`zh-HK` …）→ 中文版；其余语言 → 英文版；无语言信息兜底英文版。另有手动按钮（选择写入 `sessionStorage`），禁用 JavaScript 时由 `<noscript>` meta refresh 兜底。加 `?stay=1` 可停留在选择页预览。

## 设计说明

与同仓库另两件作品共用一套设计语言（居中卡片、双栏图文、引文块、结语通栏、图片点击放大）与完全相同的栅格：页面 1180px、图片卡 400px、正文栏 676px、栏间距 56px。

配色取自本作品图片：**深藏蓝**（#0d1b34 / #1b3866）+ **中国红**（#b52d1d）+ **描金**（#e0bb43）。页面外围是深蓝夜空（CSS 生成星点与云纹），内层是一张浅色纸张面板（顶部有三色描边），正文区保持与另两件作品一致的浅底黑字，保证阅读舒适。结语通栏用深蓝→中国红渐变，配金星点缀。

英文版沿用相同的栅格、卡片尺寸与阴影，仅按拉丁字母调整字体栈与大标题字号；对话引号改用 `&ldquo;` / `&rdquo;` 实体，避免混用中日韩全角引号。
