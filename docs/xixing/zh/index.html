誓向西行 长安月 · 大雁塔下的一句话

有些路，总要有人先走。

玄奘 大雁塔 天竺取经 誓向西行 长安月

长安城外，大雁塔下。

一个和尚站在佛像前，很久很久，没有动。

风从西边吹来，吹动他的红色袈裟，也吹动塔檐上的铜铃。他抬起头，看着佛像慈悲的眼睛，轻轻说了一句话：

佛不东去，我便西去。

“师父，您要去哪里？”旁边的小沙弥听不懂

“去天竺。去把真正的经书带回来。”他说

“可那条路，要穿过沙漠，翻过雪山，走上万里。多少人去了，就再也没有回来。”小沙弥急了

和尚笑了。他从袖中取出一卷残破的经书，翻开，指着上面的字：“你看，这里缺了一句，那里少了一段。我们念的经，是不完整的。佛经从西方传来，一路辗转，就像一碗水从远方端来，到了我们手里，已经洒了大半。”

他把经书合上，放回袖中。

“既然佛不来东方，那我就去西方。我去把那一碗水，重新端回来。”

那天夜里，他收拾好行囊，牵着马，悄悄出了城。他没有回头。

大雁塔的灯，在他身后一点点变小，最后像一颗落在人间的星星。

他往西走。月亮在他前面，像一盏为他点亮的灯。

他不知道路上会遇到什么，但他知道——有些路，总要有人先走。

文化小剧场

这个手机壳上的和尚，是唐朝的玄奘法师。他说的“佛不东去，我便西去”，意思是他不等佛法自己传到东方来，而是主动去西方求取真经。
大雁塔是玄奘从印度回来后，在长安主持修建的，用来保存他带回的经书和佛像。他走了四年，走了五万里，带回六百多部佛经，然后用一生时间把它们翻译成汉语。
后来，他的故事被写成了《西游记》。但真正的玄奘，没有孙悟空，没有白龙马，只有一双脚，和一句“我便西去”的决心。
