## 页面结构

文档内容按语义重新编排为四段结构，而不是平铺的段落堆叠：

1. **标题区**：`大漠孤行` / `长安月 · 玄奘法师与八百里莫贺延碛`
2. **图文主体**：左侧图片卡（含关键词标签），右侧故事正文；守城士兵的对话用引文块呈现，"于是，他迈出了脚步。"作为独立强调行
3. **文化小剧场**：文档中的四段史料（真实身份 / 八百里死地 / 敦煌黄色的来历 / 十七年取经数据）排成要点卡，末尾那句"你眼前的坎，算什么？"单独作收束
4. **结语通栏**：正文最后一句"只要心中有光，脚下就有路"作为全页收尾

## 双语跳转规则

入口页读取 `navigator.languages`：任一项以 `zh` 开头（`zh`、`zh-CN`、`zh-TW`、`zh-HK` …）→ 中文版；其余语言 → 英文版；无语言信息兜底英文版。另有手动按钮（选择写入 `sessionStorage`），禁用 JavaScript 时由 `<noscript>` meta refresh 兜底。加 `?stay=1` 可停留在选择页预览。

## 设计说明

与同仓库的《砖纹袈裟》共用一套设计语言（居中卡片、双栏图文、引文块、结语通栏、图片点击放大），栅格完全一致：页面 1180px、图片卡 400px、正文栏 676px、栏间距 56px。配色取自本作品图片：琥珀金 + 沙漠黄 + 落日橙，背景为 CSS 绘制的**流沙纹**肌理，结语通栏用琥珀金到落日橙的渐变。

英文版沿用相同的栅格、卡片尺寸与阴影，仅按拉丁字母调整字体栈与大标题字号。
