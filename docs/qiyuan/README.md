## 页面结构

文档是抒情叙述 + 文化解说，按情绪起伏重新编排：

1. **标题区**：`云端的小小祈愿` / `唐风守护者 · 云海与波涛之上的微笑`
2. **场景**：长安清晨的钟声，大慈恩寺塔顶的云雾，云海之上双手合十的小和尚
3. **形象与象征**：身后的金色飞檐（大唐盛世）、脚下的青色波涛（东海浪花、八十一难缩影）
4. **青色强调块**：`但他并不害怕。` 单独立起，jade 色左条 + 淡青底
5. **转折问句**：`他在祈祷什么？` 用红色左条单独成行，引出三种可能
6. **祝福卡**：结尾那句"无论生活像海浪一样如何翻涌……"放进一张云纹渐变卡里，上方标小字"他仿佛在说"
7. **文化小剧场**：文档三段解说（云端守护者的原型／红色袈裟与合十姿态／金色飞檐与青色波涛）

## 双语跳转规则

入口页读取 `navigator.languages`：任一项以 `zh` 开头（`zh`、`zh-CN`、`zh-TW`、`zh-HK` …）→ 中文版；其余语言 → 英文版；无语言信息兜底英文版。另有手动按钮（选择写入 `sessionStorage`），禁用 JavaScript 时由 `<noscript>` meta refresh 兜底。加 `?stay=1` 可停留在选择页预览。

## 设计说明

与本仓库另三件作品共用一套设计语言（居中卡片、双栏图文、引文块、结语通栏、图片点击放大）与完全相同的栅格：页面 1180px、图片卡 400px、正文栏 676px、栏间距 56px。

配色取自本作品图片：**米色祥云**（#fdfaf3 / #f9f2e4）+ **青绿波涛**（#2e6f5e / #4fa88e）+ **中国红**（#bf3a26）+ **描金**（#c9a227）。页面背景是 CSS 生成的云海肌理（多层椭圆径向渐变 + 重复径向渐变模拟祥云团），结语通栏用青绿→描金渐变，呼应"云朵柔软、海浪翻涌"这一组意象。

标题下的分隔线用四色渐变（金→红→青→金），是四件作品里唯一使用多色分隔线的一件，呼应画面里云、塔、袈裟、波涛四种元素。

英文版沿用相同的栅格、卡片尺寸与阴影，仅按拉丁字母调整字体栈与大标题字号；引号改用 `&ldquo;` / `&rdquo;` 实体。
